# LAST EXIT — roadmap

Канонический сюжет, механики и границы проекта находятся в [DESIGN.md](DESIGN.md).
Этот файл — только рабочая доска. Обновляйте строку задачи в том же PR, в котором она меняется.

**Статусы:** `planned` → `in progress` → `review` → `done`; `blocked` — требуется решение команды. Владелец — GitHub username или имя; `—` значит задача свободна.

## Как брать задачу

1. Переведите один пункт в `in progress`, укажите себя в GitHub Issue или PR.
2. Не смешивайте в одном PR несвязанные эпики.
3. Добавьте проверку: сборка обязательна, для сюжетной ветки — краткий сценарий ручного прогона.
4. После ревью отметьте пункт `done` и, если есть, добавьте ссылку на Issue/PR.
